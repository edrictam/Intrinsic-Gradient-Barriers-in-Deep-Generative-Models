# Intrinsic Gradient Barriers

Code and notebooks for *Intrinsic Gradient Barriers in Pushforward Deep Generative Models*.

Tested with Python 3.12.14 and pip 25.0.1. To reproduce the experiments:

```sh
python -m pip install -r requirements.txt
python reproduce.py
```

Figures and numerical results are saved in `figures/` and `results/`. The experiments
use analytic distributions and generated samples; no data download is needed.
